# Weak Saturation of the 3-Cube in Complete Graphs

This repository contains the manuscript and the finite verification package for

The principal results are

    wsat(K_9,Q_3) = 16,
    wsat(K_10,Q_3) = 18,
    wsat(K_11,Q_3) = 19,

and the resulting upper bound

    wsat(K_n,Q_3) <= 2n-3  for n >= 11.

## Layout

- `paper/wsat_q3.tex` — manuscript source.
- `paper/wsat_q3.pdf` — compiled manuscript after `./build_paper.sh`.
- `figures/` — TikZ figures, histogram plots, and plotting source.
- `tables/` — complete witness tables used by the manuscript.
- `supplement/programs/` — theorem-bearing searches, certificate verifiers, and the independent reference closure checker.
- `supplement/certificates/` — JSON and text certificates for n=9, 10, 11.
- `supplement/n10_reps6.bin` — complete n=10 six-edge orbit layer used by the reference closure checker.
- `supplement/n11_reps7.bin` — complete n=11 seven-edge orbit layer used by the reference closure checker.
- `logs/` — execution records supplied with the release.
- `results/closure_histograms.txt` — histogram data used for the three closure-distribution figures.
- `docs/PROOF_SPEC.md` — mathematical specification of the finite verification.
- `run_reference_checks.sh` — runs the structurally different closure implementation on the stored n=10 and n=11 representative layers.

## Mathematical reduction

Fix the canonical cube `C` on vertices 0,...,7 and the marked edge `01`. Put

    U_n = E(K_n) \ E(C).

The first-edge normalization and sequential equivalence in the manuscript give

    wsat(K_n,Q_3) = 11 + sigma_n,

where `sigma_n` is the minimum size of a seed `S` with `cl_n(S)=U_n`.
The closure is generated by the finite implications

    M(Q) \ {e} -> e,

where `M(Q)=E(Q) cap U_n` for every copy `Q` of `Q_3`.

## Verification commands

Build the manuscript:

    ./build_paper.sh

Verify the explicit certificates:

    python3 supplement/programs/verify_witness_tables.py
    python3 supplement/programs/n10_upper_verifier.py
    python3 supplement/programs/n11_upper_verifier.py

The n=9 exact verifier also checks the four-edge exclusion and the five-edge
percolating layer:

    g++ -O3 -std=c++17 supplement/programs/n9_exact_verifier.cpp -o /tmp/n9_exact_verifier
    /tmp/n9_exact_verifier

The n=10 lower-bound search is:

    g++ -O3 -std=c++17 supplement/programs/n10_lower_orbit_search.cpp -o /tmp/n10_lower_orbit_search
    /tmp/n10_lower_orbit_search

The n=11 lower-bound search is:

    g++ -O3 -std=c++17 -fopenmp supplement/programs/n11_lower_orbit7.cpp -o /tmp/n11_lower_orbit7
    /tmp/n11_lower_orbit7

The independent reference closure implementation uses a different closure
engine with antecedent counters and reverse incidence lists:

    ./run_reference_checks.sh

The reference checker reads the stored complete orbit layers and does not
regenerate them. The orbit counts themselves are checked independently by
`n11_burnside.py`.

## Reproducibility convention

The lower-bound programs use exact integer edge masks and exhaustive finite
state spaces. No random choice is used in the lower-bound theorem-bearing
searches. Heuristic search code, where present, is used only for discovery and
is not part of the lower-bound argument.

The repository release should be archived on Zenodo after the GitHub release
is created. The registered Zenodo DOI must be inserted into the manuscript
before journal submission; an unregistered DOI is deliberately not embedded
in the source.
